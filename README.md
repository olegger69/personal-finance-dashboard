# Личный финансовый дашборд

Современный адаптивный дашборд личных финансов, созданный с использованием React, Vite, Tailwind CSS и Recharts.

## Возможности

- Отслеживание доходов и расходов
- Просмотр сводных карточек с итогами
- Добавление и удаление транзакций
- Фильтрация транзакций по месяцу
- Интерактивные графики (Доходы и расходы, Расходы по категориям)
- Сохранение данных в localStorage
- Полностью адаптивный дизайн

## Технологический стек

- React 18
- Vite
- Tailwind CSS
- Recharts
- Функциональные компоненты + хуки
